Git Summary

I learned that Git is a version-control system used to track changes in a project and keep a history of my work.

Important Git commands:

git init — creates a Git repository.
git status — shows the current state of my files.
git add — stages changes for a commit.
git commit — saves a snapshot of my changes.
git branch — creates or manages branches.
git checkout — switches between branches.
git push — sends my commits to a remote repository.
git pull — gets changes from a remote repository.

Overall, I learned how Git helps me track, save, organize, and share changes to my projects.
