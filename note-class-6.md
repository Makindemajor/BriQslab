### What I Learned About Git

I learned that Git is a version control system used to track changes in files and projects. I learned how to create a repository, create branches, make changes, and save those changes using commits.

### Git Commands I Learned

* `git init` – creates a new Git repository.
* `git status` – shows the current status of the files.
* `git add .` – stages all changes.
* `git commit -m "message"` – saves changes with a message.
* `git branch` – shows available branches.
* `git checkout -b branch-name` – creates and switches to a new branch.
* `git log` – shows previous commits.
* `git push` – uploads changes to a remote repository.
