# Git Summary

Git is a version control system that helps developers track changes in their projects.

I learned how to create a Git repository using `git init`, add files using `git add`, and save changes using `git commit`. I also learned how to create and switch between branches using `git checkout -b`.

GitHub allows me to store my Git repositories online and collaborate with other developers. I learned how to push a branch to GitHub and create a pull request to merge changes into the main branch.

Some Git commands I learned are:

* `git init` – initializes a Git repository.
* `git add .` – stages files for a commit.
* `git commit -m "message"` – saves changes with a message.
* `git branch` – shows available branches.
* `git checkout -b branch-name` – creates and switches to a new branch.
* `git push` – uploads changes to GitHub.
* `git status` – shows the current state of the repository.
